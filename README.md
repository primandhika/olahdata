# Olah Data Penelitian Disertasi

Repositori ini berisi skrip dan proses pengolahan data untuk penelitian disertasi yang berjudul:

**"PENGEMBANGAN WEB MICROLEARNING BERBASIS TEKNIK FEYNMAN UNTUK MENINGKATKAN KEMAMPUAN METAKOGNITIF DALAM KETERAMPILAN BERBICARA MAHASISWA"**

## Deskripsi Proyek
Proyek ini difokuskan pada analisis data terkait pengembangan platform *microlearning*. Penelitian ini mengintegrasikan **Teknik Feynman** sebagai strategi pembelajaran untuk mengukur dan meningkatkan:
1.  **Kemampuan Metakognitif**: Kesadaran dan pengendalian proses kognitif mahasiswa.
2.  **Keterampilan Berbicara**: Kompetensi verbal mahasiswa dalam konteks akademis/praktis.

## Struktur Direktori
*   `olahdata.ipynb`: Contoh awal notebook untuk pengujian alur data.
*   `.ssh/`: (Direktori lokal) Berisi kunci SSH untuk akses repositori (diabaikan oleh git).

## Cara Penggunaan
Pastikan Anda memiliki environment Python yang sesuai dan Jupyter Notebook terinstal untuk menjalankan file `.ipynb`.
